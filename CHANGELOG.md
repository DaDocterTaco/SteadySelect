# Changelog

## 0.1.5 — 2026-10-24

- Collapsible toolbar and a button to move it to either bottom corner, with saved layout.
- Three-step guided practice using the real selection engine, with keyboard and large-button alternatives.
- Practice completion, restart and close controls; narrow-viewport fixes.
- 74 final automated checks and an installed-Chrome follow-up.

## 0.1.4 — 2026-10-24

- Reset panel scroll positions when opening Settings or reopening a panel.

## 0.1.3 — 2026-10-24

- Clearer on-page tools, settings/help, larger text/buttons, on-screen filtering and paginated results.
- Kept search and Close reachable while scrolling.

## 0.1.1–0.1.2 — 2026-10-24

- Expanded custom-button and component compatibility, styled input labels, and activation/focus safeguards.

## 0.1.0 — 2026-10-24

- Initial unpacked Chrome prototype: live outline, nearby enlarged action, searchable list, keyboard controls and preferences.

The project was informed by an October 23 selection experiment and an interactive mock. OpenAI Codex assisted planning, implementation, testing and documentation.
